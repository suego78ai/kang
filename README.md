# 🎓 프리미엄 교육과정 신청 및 관리 시스템 (EduEnroll)

현대적인 UI/UX와 세련된 다크 글래스모피즘(Glassmorphism) 테마가 적용된 **교육과정 신청 및 신청 현황 관리 웹서비스**입니다.  
별도의 백엔드 없이 프론트엔드 단독(`HTML`, `Vanilla CSS`, `Vanilla JS`)으로 구성되어 로딩 속도가 빠르며, 신청 내역은 브라우저의 `localStorage`를 통해 안전하게 유지됩니다.

---

## ✨ 핵심 기능 (Features)

1. **교육과정 탐색 (Course Explorer)**
   - 최신 기술/디자인 트렌드가 반영된 4가지 교육과정 카드 구성
   - 카테고리 필터링(전체, 개발, 디자인, 기획) 및 실시간 검색 지원
   - 세부 커리큘럼, 대상자, 일정을 확인할 수 있는 인터랙티브 상세 모달 뷰

2. **간편 신청 시스템 (Multi-step Wizard)**
   - 입력 단계별로 동적으로 진행 상태가 표시되는 멀티스텝 신청 폼
   - 전화번호, 이메일 등 입력 패턴에 대한 실시간 유효성 검사 적용
   - 안전한 개인정보 수집 및 이용 동의 절차 포함

3. **신청 관리 대시보드 (Status Dashboard)**
   - 신청한 코스들의 목록 및 현재 상태(대기 중, 심사 중, 승인 완료) 확인
   - 불필요한 신청 건에 대한 취소(삭제) 기능
   - 브라우저를 새로고침하거나 종료한 뒤 재방문해도 데이터 유지 (`localStorage` 기반)

4. **모던 UI/UX 디자인 (Modern Design System)**
   - 다크 모드 기반의 글래스모피즘 레이아웃과 생동감 넘치는 그라데이션 포인트 컬러
   - 모바일, 태블릿, 데스크톱 등 다양한 기기 화면 크기에 최적화된 반응형 웹 디자인
   - 마우스 호버 효과, 모달 애니메이션, 입력 폼 포커스 글로우 등 완성도 높은 마이크로 인터랙션

---

## 🚀 로컬에서 실행하기 (Local Run)

1. 본 저장소를 클론하거나 코드를 로컬 디렉터리에 복사합니다.
2. `index.html` 파일을 크롬 등 웹 브라우저에서 직접 더블 클릭하여 실행하거나, VS Code의 `Live Server` 확장 프로그램을 이용해 로컬 서버 상태로 열 수 있습니다.

## 🌐 GitHub Pages에 배포하기 (Deployment)

본 프로젝트는 GitHub Pages 호환 경로 설정을 가지고 있습니다. 아래 단계로 손쉽게 온라인에 배포할 수 있습니다.

1. **GitHub 원격 저장소에 코드 업로드**:
   ```bash
   git branch -M main
   git add .
   git commit -m "feat: 교육과정 신청 웹페이지 초안 완료"
   git push -u origin main
   ```

2. **GitHub Pages 활성화**:
   - GitHub의 본인 저장소(`suego78ai/kang`)로 접속합니다.
   - 우측 상단의 **Settings** 메뉴를 클릭합니다.
   - 좌측 메뉴바에서 **Pages**를 선택합니다.
   - **Build and deployment** 항목의 **Source**를 `Deploy from a branch`로 설정합니다.
   - **Branch**를 `main` (또는 배포할 브랜치) 및 `/ (root)` 폴더로 설정하고 **Save** 버튼을 누릅니다.
   - 1~2분 후 `https://suego78ai.github.io/kang/` 주소로 접속하면 정상 동작하는 웹페이지를 확인하실 수 있습니다.
