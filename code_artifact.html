구글 스프레드시트 포뮬러(수식) 팩

실제 구글 스프레드시트의 요약 영역에 그대로 복사해서 붙여넣을 수 있는 핵심 함수 목록입니다. 실시간 진척도와 통계를 자동으로 연산해 줍니다.

전체 완료 개수 집계
=COUNTIF(F2:J100, "O 완료")
미제출(누락) 개수 집계
=COUNTIF(F2:J100, "❌ 미제출")
특정 강사(예: 2행 홍길동)의 완료 진행률
=COUNTIF(F2:J2, "O 완료") / COUNTA(F2:J2)

구글 조건부 서식 세팅 팁

범위 F2:J100을 선택한 후, 메뉴의 [서식] - [조건부 서식]에서 형식 규칙을 '텍스트가 정확하게 일치함'으로 설정하고, O 완료(초록), ⚡ 검토중(노랑), ❌ 미제출(빨강) 배경을 각각 매치해 주면 화면과 같은 대시보드가 실제 구글 시트에 완성됩니다.
